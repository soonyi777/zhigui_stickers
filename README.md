## 索引用法

`sticker-catalog.tsv` 每一行对应一张原图，字段依次为：

`id`、`filename`、`render_path`、`media_type`、`animated`、`category`、`description`、`keywords`、`use_when`。

取图时优先使用 `render_path`：大多数表情直接指向原图，格式异常的 32 张则指向浏览器可显示的兼容 JPEG。

按关键词选图：

```bash
rg '抱抱|贴贴|亲亲' sticker-catalog.tsv
rg $'\t委屈哭哭\t' sticker-catalog.tsv
rg $'\tyes\t' sticker-catalog.tsv
```

编号从 `001` 到 `149`，以后新增表情包只追加新编号，不重排旧编号。

## 聊天内显示约定

- 默认尺寸：220 像素中号。
- 默认样式：圆角。
- 聊天里优先直接嵌入图片；普通远程 Markdown 图片在 Work 界面可能只留下空白占位。
